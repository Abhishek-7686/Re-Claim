# ReClaim - Requirements
#
# This project is a static front-end web app built with plain HTML, CSS,
# and vanilla JavaScript. It has NO Python/Node package dependencies --
# there is nothing to "pip install" or "npm install" to run it.
#
# ---------------------------------------------------------------------
# To run the project, you only need:
# ---------------------------------------------------------------------
# 1. A modern web browser (Chrome, Firefox, Edge, Safari - any recent version)
# 2. (Optional) Python 3.x, only if you want to serve the files locally
#    instead of opening index.html directly:
#
#       python3 -m http.server 8000
#
#    Then visit http://localhost:8000 in your browser.
#
# ---------------------------------------------------------------------
# No external libraries, frameworks, or build tools are required.
# ---------------------------------------------------------------------
