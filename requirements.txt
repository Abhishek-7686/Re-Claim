ReClaim - Requirements
======================
Note: This is a Node.js / React project, so dependencies actually
install via "npm install" (using client/package.json and
server/package.json). This file just lists everything needed,
in one place, for reference.

SYSTEM REQUIREMENTS
--------------------
- Node.js v18 or higher (comes with npm)
- MongoDB (local install OR a free MongoDB Atlas cloud cluster)
- A modern web browser (Chrome, Edge, Firefox)
- Git (only needed if you're pushing this to GitHub)

BACKEND DEPENDENCIES (server/package.json)
-------------------------------------------
express        ^4.19.2   - web server framework
mongoose       ^8.5.0    - MongoDB object modeling
bcryptjs       ^2.4.3    - password hashing
jsonwebtoken   ^9.0.2    - JWT authentication
multer         ^1.4.5    - image upload handling
cors           ^2.8.5    - allows the frontend to call this API
dotenv         ^16.4.5   - loads the .env file

dev dependency:
nodemon        ^3.1.4    - auto-restarts the server while coding (optional)

Install with:
    cd server
    npm install

FRONTEND DEPENDENCIES (client/package.json)
---------------------------------------------
react              ^18.3.1  - UI library
react-dom          ^18.3.1  - renders React into the browser
react-router-dom   ^6.26.0  - page routing / navigation

dev dependencies:
vite                    ^5.4.0  - dev server + build tool
@vitejs/plugin-react    ^4.3.1  - lets Vite understand React/JSX

Install with:
    cd client
    npm install

ENVIRONMENT VARIABLES (server/.env)
-------------------------------------
Copy server/.env.example to server/.env and fill in:
    MONGODB_URI               - your MongoDB connection string
    JWT_SECRET                 - any long random string
    ADMIN_REGISTRATION_KEY     - secret word required to register as Admin
    PORT                       - defaults to 5000

RUNNING THE PROJECT
---------------------
Terminal 1:
    cd server
    npm install
    npm start

Terminal 2:
    cd client
    npm install
    npm run dev

Then open the address Vite prints (usually http://localhost:5173).
